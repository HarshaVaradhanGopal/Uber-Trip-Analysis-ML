# 🚖 Uber Trip Analysis & Demand Prediction

## 📌 Project Overview
This project analyzes Uber pickup data from New York City to identify
temporal demand patterns and build machine learning models to forecast
hourly trip demand.

## 🎯 Business Objective
Accurate demand forecasting helps ride-hailing platforms:
- Optimize driver allocation
- Reduce passenger wait times
- Improve surge pricing strategies

## 📊 Dataset
- Uber NYC pickup data (April–September 2014)
- Source: Uber TLC FOIL Dataset (Kaggle / FiveThirtyEight)
https://www.kaggle.com/datasets/amirmotefaker/uber-dataset-from-april-to-september-2014

> ⚠️ Note: Due to GitHub file size limits, datasets are not included inthis repository. Please download the data separately to reproduce results.

2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Time-Series Train-Test Split
5. Model Building (Random Forest, Gradient Boosting)
6. Ensemble Modeling
7. Evaluation & Insights

## 📈 Results
- Tree-based models achieved strong performance using lag features.
- Ensemble model provided improved stability and accuracy.
